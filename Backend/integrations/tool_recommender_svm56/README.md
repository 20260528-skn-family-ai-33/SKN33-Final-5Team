# SVM 도구 추천 연동

기본값은 기존 추천 방식입니다. SVM 추천을 사용하려면 `A4B_TOOL_ADVICE_MODE=hint`, `A4B_TOOL_ADVICE_BACKEND=svm56`, `A4B_SVM_MODEL_PATH`, `A4B_SVM_CATALOG_PATH`를 설정합니다. 모델과 카탈로그는 신뢰할 수 있는 별도 경로에서 제공하며 저장소에 포함하지 않습니다.

옵션 추천에 필요한 Python 의존성은 `requirements.txt`에 별도로 기재했습니다. 로컬 확인에 사용한 버전은 scikit-learn 1.6.1, joblib 1.5.0, numpy 2.2.5, scipy 1.15.2입니다. 서비스의 Python 환경에서 이 파일을 설치하고 모델·카탈로그의 SHA-256 검증을 통과해야 합니다. 설정 누락이나 읽기 실패 시 전체 등록 도구를 유지하며 추천 실패 상태를 반환합니다.

추천 결과는 워크플로 설계에 참고 정보로 전달됩니다. 추천되지 않은 서비스 등록 도구도 선택할 수 있습니다. SVM 점수는 확률이 아니며, 미학습 도구는 추천 결과에서 누락될 수 있습니다. 도구 등록 여부와 실행 권한은 별도로 확인해야 합니다.

로컬 확인에서 표 열 계산 요청의 추천 목록이 계산 도구를 누락한 사례가 있었습니다. 추천 목록을 실행 허용 목록으로 사용하지 마세요.

## Qwen 연동 확인

2026-11-01, 팀 브랜치와 이 PR을 반영한 로컬 서비스에서 실제 Qwen3-8B(vLLM 0.11.0)와 SVM 힌트를 연결해 합성 JSON 표의 열 계산·JSON 저장을 한 건 확인했습니다. `read_table → calculate_columns → write_result → finish`로 실행했으며 두 행의 결과가 30과 10으로 일치했습니다. 서비스 API를 사용한 확인이며 브라우저 조작이나 배포 환경 검증은 아닙니다. 이 한 사례로 다른 도구, 복합 업무 또는 운영 성능을 보장하지 않습니다.

서버의 최대 문맥 길이가 16,384 토큰인 확인 환경에서는 `A4B_PLANNER_MAX_TOKENS=4000`, `A4B_TOOL_CATALOG_MODE=direct`를 사용했습니다. 후자는 실제 등록 도구 전체를 설계 문맥에 전달하며 SVM 목록으로 제한하지 않습니다. 출력 상한 기본값은 기존 9000이고 1~9000 사이로 조정할 수 있습니다. 입력과 출력 상한의 합이 서버 문맥 길이를 넘으면 요청이 실패할 수 있으므로 실제 모델·문맥 크기와 요청 길이에 맞춰 조정해야 합니다. 4000이 모든 요청에 충분하다는 뜻은 아닙니다. vLLM 이미지의 실행 방식에 맞춰 모델을 `--model Qwen/Qwen3-8B`로 명시하고 `/v1/models`에서 모델 ID를 확인했습니다. 서버 주소나 인증 키는 별도로 제공해야 합니다.

이름을 명시하지 않은 다른 요청에서는 Qwen이 업무 이름에 도구 ID를 넣어 검증에 실패했습니다. 이름을 명시한 합성 요청에서도 첫 초안은 같은 오류였으나 서비스의 재시도에서 올바른 이름을 생성했습니다. 이후 사용자가 이름을 별도로 지정하지 않은 경우에만 요청 문구로 표시 이름을 만드는 보완을 추가했습니다. 기존 Qwen 실패 초안을 다시 검증하고 실제 CSV를 연결해 계산·저장까지 재실행했지만, 보완 이후 새 Qwen 서버 호출은 아직 확인하지 않았습니다.

로컬 재구성본에서 빠져 있던 팀 브랜치의 CSV 파서 진입 파일을 복구한 뒤 합성 CSV의 실제 서비스 HTTP 업로드와 열 인식을 확인했습니다. 기존 Qwen 초안의 파일 연결과 근거를 해당 CSV에 맞춰 바꾸고 서비스 검증·실행기로 계산 결과를 확인했습니다. 이는 저장된 초안의 재실행으로, 새로운 Qwen 추론이 아닙니다.

## 추가 후보 실험

기본 설정에서는 기존 선택 기준을 유지합니다. `A4B_SVM_ADDITIONAL_CANDIDATE_MARGIN=-0.25`를 명시하면 등록 도구 중 기존 기준에 미달하지만 그 근처 점수인 도구를 `ml_additional_review_candidates`에 별도 표시합니다. 기존 `ml_candidates`를 바꾸지 않고, 확률·필수 도구·실행 권한으로 취급하지 않습니다. 값은 -0.4 이상 0 미만이어야 하며 이상한 설정에서는 전체 등록 도구 검토로 돌아갑니다.

이 값은 기존 AI 참고 라벨 개발 데이터에서 살펴본 실험 설정이며 운영 기준으로 확정하지 않았습니다. 추가 후보는 누락을 모두 복구하지 않습니다. 실제 표 계산 예제에서 기존 모델의 `calculate_columns` 점수는 약 -0.479였고 -0.25 후보에도 포함되지 않았습니다. 전체 등록 도구를 계속 제공해야 합니다.
