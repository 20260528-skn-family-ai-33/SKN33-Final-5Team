# SVM 도구 추천 연동

기본값은 기존 추천 방식입니다. SVM 추천을 사용하려면 `A4B_TOOL_ADVICE_MODE=hint`, `A4B_TOOL_ADVICE_BACKEND=svm56`, `A4B_SVM_MODEL_PATH`, `A4B_SVM_CATALOG_PATH`를 설정합니다. 모델과 카탈로그는 신뢰할 수 있는 별도 경로에서 제공하며 저장소에 포함하지 않습니다.

옵션 추천에 필요한 Python 의존성은 `requirements.txt`에 별도로 기재했습니다. 로컬 확인에 사용한 버전은 scikit-learn 1.6.1, joblib 1.5.0, numpy 2.2.5, scipy 1.15.2입니다. 서비스의 Python 환경에서 이 파일을 설치하고 모델·카탈로그의 SHA-256 검증을 통과해야 합니다. 설정 누락이나 읽기 실패 시 전체 등록 도구를 유지하며 추천 실패 상태를 반환합니다.

추천 결과는 워크플로 설계에 참고 정보로 전달됩니다. 추천되지 않은 서비스 등록 도구도 선택할 수 있습니다. SVM 점수는 확률이 아니며, 미학습 도구는 추천 결과에서 누락될 수 있습니다. 도구 등록 여부와 실행 권한은 별도로 확인해야 합니다.

로컬 확인에서 표 열 계산 요청의 추천 목록이 계산 도구를 누락한 사례가 있었습니다. 추천 목록을 실행 허용 목록으로 사용하지 마세요. 실제 Qwen 서버를 연결한 자연어 설계와 운영 환경 검증은 별도입니다.
