# 통합 도구와 기존 워크플로 연결

이 디렉터리는 로컬에 보관된 2026-10-27 v4 통합 도구 코드에서 가져왔다. 실행기의 Python 모듈 충돌을 막기 위해 확장 runtime을 `expansion` 패키지로 옮기고 내부 import를 상대 경로로 변경했다. 카탈로그는 이번에 연결한 여섯 도구의 아홉 operation만 발췌하여 애플리케이션 이미지의 `Backend/integrations`에 둔다. 그 외 operation은 코드가 들어 있어도 이 카탈로그의 dispatcher로 호출할 수 없다.

현재 기존 agent-builder 워크플로에 연결한 범위는 다음 여섯 도구의 아홉 가지 operation뿐이다.

- `calculate_columns`: 기존 `compute`, `rename_columns`, `parse_dates`. 날짜 변환은 대상 열과 입력 형식, IANA 시간대를 명시해야 한다. 수식에는 열 이름을 Python 식별자 형태(예: `price`, `수량`), 숫자와 `+ - * / %`, 괄호로 사용한다. 공백이 있는 열 이름, 함수 호출, 임의 코드, 덮어쓰기는 지원하지 않는다. 새 열 이름과 수식은 명시해야 한다.
- `text_transform`: 기존 `replace`. 앞 단계의 텍스트에서 지정 문자열을 그대로 변경한다. 문서 파일을 수정하거나 정규식 치환을 실행하지 않는다.
- `base64_codec`: 기존 `convert`. UTF-8 텍스트를 명시적으로 인코딩하거나 디코딩한다.
- `text_hash`: 기존 `sha256`. UTF-8 텍스트의 SHA-256 값을 계산한다.
- `date_transform`: 기존 `adjust`, `format`. ISO 날짜 문자열을 명시된 초만큼 조정하거나 지정된 출력 형식으로 표시한다. 조정에는 시간대 오프셋이 필요하다.
- `text_statistics`: 기존 `measure_text`. 글자 수 또는 공백으로 구분되는 단어 수를 센다. 글자 수는 공백 포함 여부를 지정해야 한다.

기존 서비스의 노드 설정·포트·검증·실행 결과와 연결했고, 테이블의 파일 출처와 검수 표시를 보존한다. 외부 메일·캘린더, Qwen 호출, 나머지 operation을 서비스 노드로 등록하거나 자동 실행하도록 연결한 것은 아니다. 보관된 모듈과 카탈로그에 있다는 사실은 현재 서비스의 동작 보장을 의미하지 않는다. 신규·미등록 도구는 기존 확인 경로를 유지한다.

테스트는 합성 입력을 사용한 서비스 저장·실행 및 결과 확인과 기존 회귀 검사이며, 실제 Qwen 자연어 생성이나 배포된 웹 서비스의 검증은 포함하지 않는다. 외부 API와 업무 데이터는 사용하지 않았다. `requirements.txt`는 보관된 도구 전체의 선택적 문서 처리 의존성이다. 이번에 노출한 아홉 operation은 추가 외부 서비스를 요구하지 않는다.
