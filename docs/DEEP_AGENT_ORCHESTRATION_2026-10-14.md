# Deep Agents 생성 대화 총괄 — 2026-10-14

## 바뀐 기능

사용자 요청 → Deep Agents가 도구·자료 확인 → 부족한 업무 조건 질문 → 사용자 답변 반영 → 워크플로우 설계·수정 → 검증 도구 호출 → 사용자 확인·저장 → 등록 실행 코드로 실행.

별도 DesignIntent/BusinessQuestions/DraftReview 모델과 노드별 실행 계획을 다시 생성하던 별도 모델 호출을 제거했습니다. 생성 대화의 모델 호출은 create_deep_agent로 만든 총괄 에이전트 내부에서 수행합니다. 매 턴 전체 대화·현재 초안·자료 목록·검증 오류를 전달합니다. 특정 질문·답변·노드 개수를 미리 넣지 않습니다.

list_tools: 현재 실행 가능한 도구 명세. inspect_resource: 실제 연결 자료 조회. validate_workflow: 포트·구조 검증 결과 반환. 준비된 초안이 검증 도구를 건너뛰면 같은 총괄 에이전트에게 검증을 요구합니다. 외부 검증 실패도 기존 LangGraph 수정 경로로 같은 대화 노드에 전달됩니다.

코드는 실제 스키마·근거·자료·연결을 검사하고, 질문 대기는 실행 초안을 비활성화합니다. 고정 질문을 사용자에게 생성하는 검증 경로는 제거했습니다. LangGraph는 질문·확인 대기와 저장 상태를 관리합니다. 파일 읽기·필터·집계·저장은 등록 실행 코드가 처리합니다. agent_node의 텍스트 역할만으로 실제 외부 전송이나 임의 코드 실행을 지원한다고 판단하지 않습니다.
