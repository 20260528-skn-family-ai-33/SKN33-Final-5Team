# 예약형 우선 구현·검증 결과

2026-10-12 사용자가 예약형을 먼저 구현·검증하도록 확정했습니다. 범용 자동화 플랫폼의 첫 시연이며 전체 범위를 재고 업무로 제한하지 않습니다.

## 구현 흐름

사용자가 업무 요구·자료를 입력 → Deep Agents 생성 도우미가 추가 질문·선택지를 구성 → 노드·입출력 매핑·실행 조건·예약 초안 생성 → 구조 및 조건 검토 → 설정 버전 저장 → 지금 실행 또는 서버 예약 → 실제 보고서·실행 기록 확인.

예약 트리거와 실행 기록은 실행 엔진의 공통 기능입니다. 예약·숫자 비교를 업무 LLM에 맡기지 않습니다. 재고 사례는 read_table → filter_sort → write_result → finish, 신청서 집계는 read_table → aggregate_table → write_result → finish를 사용합니다. 업종별 코드나 답안을 추가하지 않았습니다. 워크플로우 정의·인자만 다릅니다.

## 저장과 실행

- 기존 로컬 SQLite에 설정 버전·자료·체크포인트·실행을 보존합니다.
- 추가한 공통 테이블: 관리 데이터 소스, 예약, 예약 작업. 업무별 별도 DB는 없습니다.
- 관리 데이터 소스 갱신은 새로운 파일 ID와 소스 버전을 연결합니다. 예약 시작 때 입력 버전을 고정하고 이후 변경은 다음 실행에 반영합니다.
- 예약은 매일/매주·IANA 시간대·시각·요일을 저장합니다. 설정 저장 직후 중지 상태이며 사용자가 예약 켜기로 활성화합니다.
- Node 서버가 5초마다 만기 작업을 확인합니다. 동일 예약 시각의 작업은 유일 키, DB 트랜잭션, 작업 임대 토큰으로 중복 획득을 막습니다.
- 서버가 중단된 작업은 임대 만료 후 재획득합니다. 동일 작업 ID·체크포인트·보고서 경로를 재사용합니다. 누락된 과거 정규 예약은 재시작 시 한 회만 실행하고 다음 미래 시각으로 이동합니다.
- 보고서는 서버 `data/reports/`에 원자적으로 저장하며 실제 파일을 다운로드합니다. 설정 버전·소스 버전·실행 ID·트리거·단계 인자·오류를 확인할 수 있습니다.

## 실제 검증

1. 새 생성 대화의 시간대·처리 정책 확인과 사용자 답변 반영.
2. 재고 보고서 지금 실행: 키보드·마우스 2행. 같은 수량인 모니터와 빈 재고는 제외.
3. 관리 CSV를 갱신한 후 15초 시험 예약을 실제 서버 타이머로 실행: 새 자료의 케이블 1행. 소스 v2, 동일 작업 1건.
4. 비숫자 값: 실패 상태·실패 단계·오류 기록, 보고서 없음.
5. 부족 상품 없음: 성공 상태, 원래 열 제목이 있는 빈 CSV.
6. 같은 생성 구조의 주간 신청서 집계: 접수 2, 완료 1, 검토 1, 빈 상태 1.
7. 서버 재시작 후 예약 규칙·중지 상태·소스 버전 유지, 다운로드 파일 바이트와 저장 결과 동일.
8. Python 테스트 45개 통과. 서버 테스트 508개 중 507개 통과·기존 1개 제외. TypeScript 검사·프런트/서버 빌드 통과.

실제 모델 검증 기록은 SCHEDULED_WORKFLOW_LIVE_CHECK.json, WEEKLY_WORKFLOW_CHECK.json, SCHEDULE_RESTART_DOWNLOAD_CHECK.json에 있습니다. 새 생성 대화 확인 결과는 SCHEDULE_CREATION_FRESH_CHECK.json에 기록합니다.

## 수정한 문제

잘못된 포트 연결, 실제로 전달하지 않는 출력 참조, 사용자 조건과 실행 인자 불일치, 빈 값 유지 시 다른 필터 무시, 빈 값 제외만 수행 시 누락 미처리, 큰 파일 Base64 검사 스택 오류, 설정 상태와 실행 상태 혼동을 보완했습니다. 실행 규칙을 사용자 발언 기준으로 별도 구성·검토하며 실제 결과를 독립 정답과 비교했습니다. 표 처리 설명·지시사항은 확정된 실행 인자에서 직접 생성해 화면 설명과 실행 정책의 충돌을 제거했습니다.

LLM 생성과 검토가 모든 요청의 의미 정확성을 보증하지는 않습니다. 미등록 도구·지원 범위 밖 요청은 연결 필요 또는 미지원으로 표시하고 저장·실행을 제한합니다.

## 시연 범위

현재는 로컬 단일 사용자 데모입니다. 매일·매주 예약과 업로드 관리 표 소스 갱신을 지원합니다. 현재 PC의 서버가 꺼지면 실행이 중단됩니다. AWS 등 상시 서버 배포, 외부 파일 변경 감지·외부 API 소스 연결, 기업 인증·권한·장애 운영은 별도 확장입니다. 15초 시험 예약은 시험으로 표시하며 정규 오전 9시 실행과 구분합니다. 검증 후 예약은 중지 상태로 두었습니다.
