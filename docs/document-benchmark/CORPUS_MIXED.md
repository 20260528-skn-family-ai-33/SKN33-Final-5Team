# 전체 코퍼스 혼합 재실행

기본 16종 묶음 시험은 같은 형식 5개·10개, 전체 6형식 혼합, 같은 이름,
손상 파일 격리와 입력 순서 변경을 확인한다. 이와 별도로 팀장안의
“전체를 혼합 묶음으로 다시 실행” 조건을 충족하도록 모든 고정 입력을
한 번씩 더 업로드한다.

- 기본 manifest의 입력·정답·ID·SHA-256을 그대로 재사용한다.
- 179개 입력 전체를 서비스 상한인 최대 10개씩 18세션에 배치한다.
- 정렬 기준은 CSV, PDF, XLSX, JSON, TXT, MD의 형식 순서와 고정 corpus ID다.
  순서대로 18개 세션에 순환 배치하므로 모든 세션에 PDF와 CSV가 포함된다.
- 18개 공개 PDF, 100개 공개 CSV, 60개 보존 시험과 손상 파일 1개가
  각각 정확히 한 번 들어간다. 파서 출력이나 점수로 사례를 고르지 않는다.
- 혼합 명세를 별도 파일로 먼저 고정하고, 기본 단일·경계 시험이 끝난 뒤
  같은 코드·모델·Pod에서 `--phase bundles`로 실행한다.
- 기본 572회에 358회를 더해 전체 검증은 A/B 총 930회 업로드다.
- 공개 자료의 단일 입력·혼합 입력 지표와 파일별 의미 해시를 비교한다.
  실패·수식 캐시 경고·출처 오류도 함께 비교하며, 성공 파일만 선택하지 않는다.
