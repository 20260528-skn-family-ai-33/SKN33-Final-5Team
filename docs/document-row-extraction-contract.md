# 문서 표 추출의 행 보존 계약

## 문제와 변경

문서 항목을 CSV로 정리할 때 단일 값 추출을 선택하면 열마다 한 값만 남고, 값이 인용문에 있는지만 확인한 `verified`가 행 누락을 감추었다. 이번 변경은 문서 종류나 특정 열 이름·정답 행 수를 코드 분기에 추가하지 않는다.

- 원본 파서가 제공한 표 셀의 행·열·병합 정보를 문서 읽기 출력에 보존한다. 여러 텍스트 청크에 같은 표 구조를 중복 첨부하지 않는다.
- 요청한 열 이름을 표의 머리글과 대응하고 좌표별 데이터 행을 그대로 추출한다. 중복 품명과 빈 셀을 유지한다. 텍스트 근접 순서로 서로 다른 행의 값을 묶지 않는다.
- 고정 레시피와 일반 설계 경로 모두 반복 표를 단일 값 추출로 낮추지 않도록 생성·저장을 검사한다. 실행 때도 재검사해 기존에 저장된 잘못된 설정의 부분 추출을 막는다.
- CSV에는 사용자가 요청한 열만 내보낸다. file_name, row, status, evidence, row_coverage는 실행 기록 내부에 보존한다.
- 값의 인용 근거와 파서 표의 행 대응 확인을 구분한다. 표 구조를 확인할 수 없는 모델 행 추출은 `row_coverage=unverified`로 남기고 완성된 파일 내보내기를 중단한다. 병합 셀·누락 셀·불명확한 머리글·미검토 파서 결과·제한 초과도 일부만 조용히 저장하지 않는다.
- 반복 표와 무관한 문서당 단일 값 추출은 기존 fields 계약을 유지한다.

## 검증 및 한계

납품서 정답 값은 사용자 제공 합성 PDF의 화면을 대조하여 회귀 fixture에 기록했다. 파서 계약 형태의 표 셀 fixture, 모의 질문 모델, 실제 설계 그래프·SQLite 저장·워크플로우 실행·CSV 내용 비교를 사용한다. 원본 PDF는 스캔형으로 로컬 텍스트 추출 결과가 없으며, 운영 MinerU/OCR·운영 LLM·운영 DB를 호출한 검증은 아니다.

`complete`는 전달받은 **파서 표 구조 안의 행 대응**을 의미한다. OCR이 원본 이미지의 행 자체를 누락했는지까지 증명하지 않는다. 이는 파서 품질 평가·원본 대조에서 따로 검증해야 한다. 표 구조를 제공하지 않는 기존 OCR 자료의 행 추출도 더 이상 인용 검사만으로 파일 저장을 완료하지 않으므로, 해당 자료는 파서 표 인식 결과를 검토해야 한다.
