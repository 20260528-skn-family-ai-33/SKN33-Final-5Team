# 팀원 피드백 반영 현황

기준: 2026-11-02 로컬 작업본. 아래의 검증은 지정한 합성 사례와 개발 검증에 관한 결과다. 모든 기능의 운영 성공률을 뜻하지 않는다.

## 완료했거나 후보를 마련한 작업

| 팀원 피드백 | 이번까지 진행한 일 | 확인 범위 |
|---|---|---|
| 모델과 서비스 연결 | SVM 점수를 확률이 아닌 참고 점수로 다루고, 추천 실패 시 전체 등록 도구를 볼 수 있는 연결을 마련했다. 모델을 실행 권한이나 화이트리스트로 사용하지 않는다. | 선택형 연결 PR #16은 병합됐다. 팀원 브랜치 기준 추가 도구 연결은 초안 PR #17과 이번 후속 작업에 있다. 모델 파일은 별도 지정해야 한다. |
| 서비스 도구 대응 | 실제 실행 registry와 56개 모델 기능을 대조했다. `write_result`와 `export_result`의 입력과 기능을 구분했다. 기존 도구 코드를 재사용해 표 열 계산, 문자열·날짜·JSON·목록 처리, 두 표 결합·비교, 단일 수식 계산 등의 로컬 연결 후보를 추가했다. | 로컬 후보 registry 27개에는 제어 항목도 포함된다. 56개 전체가 연결된 것은 아니다. 각 항목의 지원 범위는 코드와 도구 설명을 확인해야 한다. |
| 검수 도구 학습 사례 | `reply_review`, `review_summary`의 AI 합성 사례를 보강해 별도 후보 모델을 학습했다. 기존 모델을 자동 교체하지 않았다. | 개발용 합성 사례에서 확인한 결과이며 실제 사용자 대상 성능을 증명하지 않는다. 부정 표현과 표/문단 구분에서 오탐·누락이 남는다. |
| 데이터 정합성 | C082의 `calculate_columns` 라벨과 관련 목록·operation 기록을 별도 사본에서 동기화하고 원본을 보존했다. | 중복 필드 정리다. 데이터의 의미 정답 전체를 인증한 것은 아니다. |
| 라벨 이견 | 이견 102셀을 검토해 31셀을 수정하고 71셀은 미확인으로 남겼다. 후속 재검토 기록을 별도로 유지한다. | AI 검토 기록이며 사람 gold나 업무 실행 결과가 아니다. 최신 사본과 세부 판정은 `개발검증` 및 기존 전체 자료를 참조한다. |
| 검증기와 실행 | 근거 인용 검사, 제한적인 곱셈 대조, 문서 없는 단일 수식 대조, 누락된 노드 재작성 기회 등을 보완했다. 실제 Qwen과 로컬 서비스에서 단일 수식 `(8+4)*2`가 생성·저장·실행되어 `24`를 반환했다. 이전 수정본에서는 명시적 두 표 결합 요청 한 건이 `30, 10, 10`으로 실행됐다. | 개별 합성 사례다. 최신 후속 수정본의 두 표 요청은 재확인 시 통과하지 못했다. 실제 외부 발송은 하지 않았다. |

## 아직 남은 작업

1. **복합 흐름 생성 안정화:** 최신 수정본에서 검수 흐름은 노드 누락·판정 보류가, 두 표 흐름은 근거 인용·설정 오류가 발생했다. 실패 원인을 고치고 여러 표현과 입력으로 생성·저장·실행 및 결과를 다시 확인해야 한다.
2. **검수 결과의 의미 정확도:** 직접 구성한 검수 흐름은 실행됐지만 정책의 의미를 잘못 해석한 사례가 있다. 인용이 정확해도 의미 판단이 정확하다는 뜻은 아니다. 검수 도구의 재현율과 오탐을 별도 검토 자료에서 확인해야 한다.
3. **지원 범위와 도구 계약 확정:** 서비스에서 실제 사용할 도구, operation, 입력·출력, 동적 도구 등록 및 미등록 도구의 처리 방식을 팀과 맞춰야 한다. 메일·캘린더 등 외부 기능은 별도 연결과 권한이 필요하다.
4. **모델·데이터 확정과 평가:** 미확인은 계속 마스킹하고, 복합·희소·지원 불가 요청을 포함해 학습에 사용하지 않은 평가 자료로 확인해야 한다. 현 개발 점수는 AI 참고 라벨과 모델 선택을 포함한다. 56개를 모두 추천할 수 있다는 뜻이 아니다.
5. **서비스 통합:** 모델 배포 경로·의존성·팀 브랜치와의 통합, 수동 선택·빈 추천·미학습 도구 처리, 파일 매핑 UI, 실제 배포 환경 확인이 필요하다. PR은 검토용이며 병합과 배포는 별도다.
