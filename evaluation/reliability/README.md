# 현재 Git 기반 30문항 회귀 평가

이 평가기는 초안 생성·확인·저장·실행 worker를 호출합니다. 코드 생성 에이전트나 학습 adapter를 추가하지 않습니다. 지원 요청25개와 지원 불가5개를 구분하고, 질문·자료·기대 결과는 questions.json에 고정합니다. 질문 hash는 manifest.json에 있습니다.

프로젝트 루트에서 기존 Python 환경을 사용합니다. API 키는 환경변수로만 전달하세요. 실행은 실제 모델 API를 호출합니다.

```bash
export A4B_EVAL_API_KEY='<키>'
export A4B_EVAL_MODEL='gpt-4.1-mini'
export A4B_EVAL_OUTPUT='/절대경로/새평가폴더'
Backend/.venv-agent/bin/python evaluation/reliability/evaluate.py
```

각 case는 별도 SQLite 디렉터리에서 실행됩니다. 원본 서비스 DB는 사용하지 않습니다. 같은 출력폴더에서 완료된 case는 재사용하므로 새 모델·프롬프트·코드 비교에는 새로운 A4B_EVAL_OUTPUT을 지정하세요. --case N01,N02로 특정 문항만 선택할 수 있습니다.

출력의 private-runs에는 합성 실행 DB가 포함되어 공유 대상에서 제외합니다. results는 원시 결과이며 공유할 때 credential_id를 가리세요. 키 문자열은 저장 전 제거합니다.

이30개는 개발용 반복 검증입니다. 미공개 독립 벤치마크가 아닙니다. 수정 전/후는 모델·질문·입력·정답·채점기를 유지하되 제품 코드만 바꿉니다. 저장·실행 성공과 최초 판단/업무 결과 전체 일치는 구분하세요. 파일명·실제 파일바이트·필드 값·원문 근거·검수·승인 대기를 검사하며 자유 서술의 완전한 의미 판단은 자동 지표만으로 보장하지 않습니다.

제공된 100샘플 평가 묶음에서 채택한 원칙은 입력/정답 분리, 실제 저장 파일 검사, 명시적 질문·미지원 기대 상태, 격리된 fixture 실행, 소스/질문 해시와 실패 보존입니다. 제공 evaluator를 그대로 복사해 다른 그래프를 주입하지 않습니다.
