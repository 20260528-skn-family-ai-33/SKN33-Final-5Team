모델·계정 대체값을 사용하는 이 검사와 실제 Qwen의 생성 성공을 구분한다.

- 동작이 서로 다른 도구의 인자·포트를 섞던 생성 규격과 JSON 문자열 재인코딩.

- 모든 노드에 불필요한 빈 설정을 생성하던 규격과 간소화된 설정의 기본값 복원.
- 16K 모델 문맥 한도를 넘도록 중복되던 카탈로그·도구 계약. 모든 ID는 유지하고

실제 생성·저장·실행에 성공했고 예상 B/C 행을 반환했다. 나머지 실제 모델 사례는

## 통합 리뷰에서 확인된 상태

arguments_json의 group_by/value_column을 변경하며 기존 정책은 보존한다.
재사용 하위 워크플로우에도 실행 시 파일 목록을 전달한다. JSON 표 선택 노드의
라이브러리 저장·재조회 및 실행도 검사한다.

문답 수정에는 남은 문제가 있다. 업로드 사전 확인은 지원 판단 뒤에 있고,
단순 긍정 답변은 지원 판단을 다시 호출할 수 있다. keep만 남은 중복 제거 요청은
질문이 없어져도 manual_review로 남을 수 있다. 이 항목을 완료로 간주하지 않는다.
추론 문구 표시 보완은 제한된 표현 검사이며 모든 모델 출력의 추론 제거를 보장하지 않는다.
