CAPABILITY → COMBINED는 지원 판단을 고정하고 표 Planner의 추가 효과를 본다. H32는 이 표 경로를 사용하지 않는다. TABLE → COMBINED는 표 Planner를 고정하고 지원 판단의 추가 효과를 본다. H01과 H21은 이 문서 전달 경로를 사용하지 않는다. 해당 대조의 변경 범위 밖 사례도 함께 제시했다.

모델 로드는 네이티브 응답에서 반환한 값만 합산했다. Planner SDK 응답의 서버 내부 로드는 미기록이다. 로드와 모델 호출 시간은 사용자 지연에 포함된다. 단순 차감 값을 사용자 체감 시간으로 해석할 수 없다. p50은 세 사례 전체 시간의 중앙값이며 턴 중앙값이나 전체 서비스 중앙값으로 확대하지 않는다.

아래 명령은 이미 저장된 원본을 읽어 표를 다시 만든다. 각 후보와 기준본의 단계별 wall, 토큰, 모델 로드 관측 횟수, 앱 파일 해시 변화, 턴별 시간을 보려면 같은 폴더의 compare.py를 쓴다.

```powershell
$experiment = 'runtime/planner-capability-9b-experiment'
& $worker "$experiment/render-results.py"
& $worker "$experiment/compare.py" "$experiment/CAPABILITY.json" "$experiment/COMBINED.json"
& $worker "$experiment/compare.py" "$experiment/TABLE.json" "$experiment/COMBINED.json"
```
